# 옹알송 웹앱

iPhone Safari에서 열고 홈 화면에 추가해서 앱처럼 쓰는 개인용 웹앱입니다.

## 바로 테스트하기

Mac에서 미리 보려면 이 폴더에서 간단한 서버를 켜면 됩니다.

```sh
python3 -m http.server 5173
```

그다음 Mac Safari에서 `http://localhost:5173`을 엽니다.

## iPhone에서 앱처럼 쓰기

iPhone 마이크 녹음은 Safari 보안 정책상 `https` 주소에서 열어야 안정적으로 작동합니다. 이 폴더를 GitHub Pages, Netlify, Vercel 같은 정적 호스팅에 올린 뒤 iPhone Safari에서 그 주소를 여세요.

Safari에서 주소를 연 뒤:

1. 공유 버튼을 누릅니다.
2. `홈 화면에 추가`를 누릅니다.
3. 이름을 `옹알송`으로 두고 추가합니다.

이후 홈 화면 아이콘으로 실행하면 앱처럼 열립니다.

## 사용 흐름

1. `녹음 시작`
2. 아기 옹알이를 5초 이상 녹음
3. `녹음 멈추기`
4. 분위기 선택
5. `음악 만들기`
6. 재생, 저장, 공유

기존 음성 메모는 `녹음 파일 불러오기`로 사용할 수 있습니다. 파일은 15MB 이하, 1분 이하를 선택하세요. 직접 녹음은 1분이 되면 자동으로 멈춥니다. 다른 앱으로 이동하면 녹음을 멈추고 분석합니다.

최근 녹음과 만든 노래 한 개는 브라우저 보관함에 자동 저장됩니다. 새로고침해도 다시 불러오지만, Safari 웹사이트 데이터를 지우거나 기기가 저장 공간을 정리하면 사라질 수 있습니다. 남겨두고 싶은 소리는 `원본 저장`과 `노래 저장`으로 별도 보관하세요. 새 녹음에 성공하면 이전 작업을 대체하며, 휴지통 버튼은 최근 녹음과 노래를 모두 지웁니다.

이 앱은 소리의 크기와 높낮이를 분석해 멜로디를 만드는 실험적인 도구입니다. 아기 옹알이와 주변 사람의 말소리를 구분하지는 않습니다.

녹음과 음악 생성은 브라우저 안에서 처리됩니다. 이 앱은 서버로 녹음 파일을 업로드하지 않습니다.
